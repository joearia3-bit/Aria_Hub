# Aria Hub

A simple marketplace app for posting product and service listings in Papua New Guinea.

## Features
- Create listings with name, category, price (K), location, and description
- View all saved listings
- Built-in help manual via the ? button

## Running locally
Open `index.html` in a web browser. No installation needed.

## Notes
Listings are saved in the browser's local storage, so they stay on that device only.
